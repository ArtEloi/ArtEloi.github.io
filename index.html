Criativo

Criativo é a ferramenta interna de publicação do canal do YouTube Casos do Arquivista, que conta histórias reais a partir de documentos de época.

O aplicativo usa a API de dados do YouTube apenas para enviar vídeos, miniaturas e metadados ao canal do próprio responsável. Ele não é oferecido a terceiros e não coleta dados de outros usuários.

Política de Privacidade · Termos de Uso

English

Criativo is the internal publishing tool of the YouTube channel Casos do Arquivista. It uses the YouTube Data API only to upload videos, thumbnails and metadata to the owner's own channel. It is not offered to third parties and does not collect data from other users.
